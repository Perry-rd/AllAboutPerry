Asset upload guide

images/   Profile photo and general portfolio imagery.
projects/ Project screenshots, grouped by project name when multiple images exist.
icons/    Custom icons or approved visual assets.
cv/       CV/resume files. Replace [CV FILE] in index.html with the exact filename.

When adding project files, keep filenames descriptive, for example:
projects/project-name-overview.png
projects/project-name-detail.png
